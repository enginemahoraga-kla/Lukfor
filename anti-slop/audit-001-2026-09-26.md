# Audit anti-slop 001: Lukfor UI

Tanggal: 2026-09-26
Mode: **After** (audit dulu, perbaikan hanya untuk nomor yang disetujui)
Cakupan: panel pencarian (`src/App.tsx`, `src/styles.css`), termasuk fitur favorit yang baru ditambahkan.
Versi antislop: 3.2.13 (core + antislop-ui + antislop-human)

Prioritas mengikuti tier aturan: Hard Gate = **HIGH**, Purpose-Gate = **MEDIUM**, Quality Lock = **LOW**.

## Cara audit ini dibuat

- Kontras diukur dengan `contrast-check.py` dari antislop-human, bukan dikira-kira. Latar panel diambil `#18181c`; baris terpilih (ungu 16% di atas panel) dihitung `#2a283f`.
- UI dijalankan di browser dengan backend Tauri dipalsukan (`mockIPC`), lalu setiap alur diklik satu per satu. Klik-through lengkap ada di bagian bawah.

---

## HIGH (Hard Gate)

**1. R-25: teks sekunder tidak terbaca.**
`#63636d` dipakai untuk path, label "App", baris hint, dan "Enter to copy". Kontras **2,98:1** di panel dan **2,40:1** di baris terpilih. Minimum 4,5:1. (`styles.css` `.row .sub`, `.row.hint .name`)

**2. R-25: placeholder dan footer tidak terbaca.**
`#55555e` untuk "Search Lukfor…" dan footer: **2,40:1**. Footer bukan hiasan: di situlah tertulis hotkey mana yang *benar-benar* aktif (Lukfor bisa jatuh ke Ctrl+Shift+Space) dan status indexing.

**3. R-32: posisi keyboard di daftar hampir tak terlihat.**
Sorotan baris terpilih adalah satu-satunya penanda posisi saat navigasi dengan panah, dan kontrasnya terhadap panel hanya **1,24:1**. Minimum untuk elemen non-teks 3:1.

**4. R-32: `outline: none` tanpa pengganti.**
Input pencarian menghapus outline (`styles.css:70`) dan tidak menggantinya. Fokus hanya ditandai caret.

**5. R-32: pembaca layar tidak mendapat apa-apa.**
Daftar hasil tidak punya role `listbox`/`option`, tidak ada `aria-activedescendant`, dan input tidak berlabel (hanya placeholder). Pengguna pembaca layar bisa menekan panah, tapi tidak pernah diberi tahu apa yang sedang terpilih.

**6. R-26: baris hint tampak bisa dipilih tapi tidak melakukan apa-apa.**
Baris hint pertama mendapat sorotan "terpilih" seperti hasil sungguhan, tapi Enter di layar kosong tidak melakukan apa pun. Terkait: mengetik `g:` saja lalu Enter membuka Google untuk kata harfiah "g:".

**7. R-27: pencarian dan clipboard tidak punya kondisi galat.**
Panggilan `search` dan `clipboard_history` tidak menangani kegagalan. Kalau backend gagal, daftar lama tetap tampil seolah-olah itu jawabannya. (Favorit dan membuka entri sudah menangani galat sejak perubahan ini.)

**8. R-02: em dash di teks UI.**
"No results — press Enter to search Google" (`App.tsx`).

**9. R-37: tidak ada arah desain.**
Tidak ada `DESIGN.md` dan tidak ada dial (ENERGY / RHYTHM / MOTION) yang dideklarasikan. Tampilan sekarang dibangun tanpa arah. Kamu memilih **"punya karakter sendiri"**, jadi arahnya harus datang darimu; pertanyaannya ada di akhir laporan.

## MEDIUM (Purpose-Gate)

**10. R-01, R-29: palet ungu-di-atas-hitam.**
`#8b7cf6` di atas `#18181c` persis pola "purple-and-black" yang terdaftar sebagai palet default AI, tanpa alasan merek tertulis. Aksennya juga tersebar: ikon prompt, caret, tint baris terpilih, glyph ikon, bintang favorit. Aksen yang ada di mana-mana berhenti jadi aksen.

**11. R-04: berlian ◆ sebagai prompt.**
Diamond ada di daftar ikon generik AI dan di sini tidak menandai apa pun.

**12. R-04: emoji berwarna sebagai ikon jenis.**
📁 📄 🌐 📋 dirender font emoji Windows dalam warna penuh, bersebelahan dengan glyph ▸ yang monokrom dan ikon app asli. Bahasa ikonnya campur aduk, dan emoji folder menambah warna oranye ke palet.

**13. R-19: animasi buka mengabaikan `prefers-reduced-motion`.**
Fade 120 ms punya tujuan (menandai panel muncul), tapi tetap jalan untuk pengguna yang meminta gerak dikurangi.

## LOW (Quality Lock)

**14. R-21: tema gelap permanen tanpa alasan tertulis.**
Tidak mengikuti setelan terang/gelap Windows dan tidak ada pilihan lain.

**15. R-31: semua pesan flash berwarna hijau, termasuk galat.**
"Couldn't open it", "Not found anymore", dan "Couldn't save favorites" tampil dengan hijau yang sama dengan "Copied". Hijau dibaca sebagai "berhasil".

**16. R-31: bintang favorit kehilangan warnanya saat di-hover.** *(dari fitur favorit yang baru)*
Di bawah kursor, bintang terisi dan kosong sama-sama putih, jadi statusnya tidak terbaca tepat saat kamu hendak mengkliknya. Statusnya sendiri benar (dicek di DOM: `aria-pressed`).

**17. R-31: tips perintah hilang begitu ada favorit.**
`g:`, `cb`, `Ctrl+R`, dan `Ctrl+D` hanya tertulis di layar kosong tanpa favorit. Setelah kamu mem-pin satu hal, tidak ada lagi tempat yang menyebutkannya.

**18. R-20: tes tukar-logo gagal.**
Ganti nama "Lukfor" dengan nama lain dan tampilannya tetap bisa jadi launcher gelap mana pun. Diselesaikan lewat arah desain (#9).

**19. R-31: bahasa UI tidak diputuskan.**
UI berbahasa Inggris, sementara README dan penggunanya berbahasa Indonesia. Kalau nomor ini dipilih, UI saya ubah ke Bahasa Indonesia.

## Yang lolos

- **R-12 shadow:** satu panel yang melayang di atas desktop; elevasi memang intinya.
- **R-11 radius:** tiga tingkat (14 / 8 / 6 px) yang membedakan panel, baris, dan tombol.
- **R-04 bintang ★ untuk favorit:** bintang ada di daftar ikon generik AI, tapi di sini fungsinya jelas: penanda favorit yang dikenal umum.
- **R-25 bagian favorit:** bintang belum di-pin 5,25:1, bintang ter-pin di baris terpilih 6,06:1, nama favorit hilang 5,25:1.
- **R-33, R-35:** fitur ditulis langsung di source; app dijalankan dan diklik (lihat bawah).

## Tidak berlaku

- **R-03 mobile:** jendela desktop berukuran tetap 660×460, tidak ada breakpoint.
- **R-17, R-18, R-24, R-28, R-36, R-38:** tidak ada statistik, testimoni, navbar, FAQ, atau klaim.

## Klik-through (R-35)

Dijalankan di harness browser dengan backend dipalsukan; tiap langkah dibuktikan dari log panggilan IPC atau DOM, bukan hanya dari screenshot.

| Aksi | Hasil |
|---|---|
| Buka panel, kolom kosong | Daftar favorit tampil; favorit yang hilang dari index ditandai "Not found" |
| Enter pada favorit yang hilang | Pesan "Not found anymore. Ctrl+D unpins it"; `open_entry` tidak dipanggil |
| Ctrl+D pada favorit yang hilang | Terlepas; sorotan jatuh ke baris yang tersisa |
| Ketik `notes`, Ctrl+D pada hasil ke-2 | Ter-pin, naik ke posisi 1, **sorotan ikut naik** (bug ditemukan dan diperbaiki di sesi ini) |
| Ctrl+D lagi | Melepas item yang **sama** (log: dua toggle pada path yang sama) |
| Klik bintang dengan mouse | Ter-pin; `open_entry` dan `hide_window` tidak dipanggil |
| Enter pada entri yang rusak | Pesan "Couldn't open it. Ctrl+R rebuilds the index"; jendela tetap terbuka |
| Ctrl+D pada baris kalkulator | Pesan "Only apps, files and folders can be pinned"; tidak ada toggle |
| Enter pada favorit | `open_entry` lalu `hide_window` |
| Lepas semua favorit | Kondisi kosong: "No favorites yet. Select a result and press Ctrl+D to pin it here." |
| `list_favorites` gagal | "Couldn't load favorites. Search still works." |
| Esc | `hide_window` |
| Error JavaScript selama semua langkah di atas | Nol |
